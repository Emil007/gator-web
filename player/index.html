How this is 1:1

scripts/recompile_to_js.py translates each SM83 instruction in banks 0–2 into a JS function with the same semantics (registers, flags, banks, memory). That is static recompilation — not EmulatorJS and not a fetch/decode/execute loop. Bank 3 stays ROM data (tiles) read by the game itself.
